Основные направления: многопоточные runtimes, планировщики задач,

Разрабатываю \textbf{DagFlow} (C++23 task runtime) и
\textbf{CMakeWorkflow} (.NET 10, система оркестрации CMake/Ninja).
Уделяю особое внимание семантике конкурентного выполнения,
жизненному циклу процессов, воспроизводимости результатов
и проверке корректности через property-based testing,
fuzzing и sanitizers.

\project
    {DagFlow --- C++23 task runtime и work-stealing scheduler}
    {https://github.com/cpp20120/DagFlow}
    {GitHub}

\begin{itemize}
    \item Разрабатываю многопоточный планировщик задач
    с work stealing (Chase--Lev), шардированными очередями,
    back-pressure, приоритетами, affinity
    и ограничением конкурентности.

    \item Реализовал API для DAG, task scope,
    completion и параллельной обработки диапазонов;
    прорабатываю явное владение ресурсами,
    завершение задач и shutdown semantics.

    \item Разработал property-based и stateful тесты
    для очередей, storage, graph, pool и scope.
    Использую Relacy, ASan/TSan, fuzzing
    и кроссплатформенную CI для проверки корректности.

    \item В локальном benchmark \texttt{for\_each\_ws}
    обработка $10^6$ элементов достигает
    около 104 млн элементов/с.
    Результат относится к конкретному сценарию нагрузки.
\end{itemize}
