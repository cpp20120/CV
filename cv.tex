  \item Добавил поддержку CMake Presets и подключения существующего build tree; учёт multi-config/single-config сборок, ограничение конфликтующих операций над одним деревом.

  \item Разработал workflow-генераторы для benchmark, profile и test/build matrix; интеграцию с \texttt{perf} на Linux и подготовку проверок окружения (doctor/fix).

\end{itemize}

\textbf{DagFlow --- C++23 task runtime и work-stealing scheduler} \hfill \href{https://github.com/cpp20120/DagFlow}{GitHub}\\
\begin{itemize}
  \item Разрабатываю планировщик задач с work stealing (Chase--Lev), шардингом очередей, ограничением нагрузки (back-pressure), приоритетами, affinity и управлением конкурентностью.
  \item Реализовал API для DAG, scope, task completion и параллельной обработки диапазонов; прорабатываю явное владение ресурсами, завершение задач и shutdown semantics.
  \item Создал набор property-based/stateful тестов для очередей, storage, graph, pool и scope; применяю Relacy для проверки сценариев конкурентного доступа, ASan/TSan, fuzzing и cross-platform CI.
  \item Отдельный \texttt{for\_each\_ws}: в локальном замере на $10^6$ элементах --- около 104 млн элементов/с. Результат относится к конкретному сценарию и не характеризует производительность всех типов задач.
\end{itemize}
